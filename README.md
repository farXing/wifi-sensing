## Цель проекта

Ведение первого проекта в git, а также его правильное оформление. Изучение работы с платами (ESP-32) как радаром и приёмником wifi сигнала. Собрание датасета из данных приёмника для различных состояний человека в комнате. Создание нейронной сети с нуля для обработки данных, изучение работы нейросетей. Как итог, модель, определяющая состояние человека по данным с приёмника.
